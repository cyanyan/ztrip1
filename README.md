关于屏幕 z 轴的实验。


每月会更新 13 张图片， 每张图片是和我之间的距离产生的结果，放在屏幕上时，它们是动态的。
在 z 轴上的任意一次变化，也算一次旅程。


Experimenting with the Screen’s Z-Axis（ongoing）
Thirteen images are updated each month.
Each image comes from a certain distance between me and it — and this distance can change once it’s on the screen.
Every change along the Z-axis is like taking a small journey.
